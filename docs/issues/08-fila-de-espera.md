## Contexto
Se uma data é segurada por outra proposta e cai, quem pediu depois deveria ser avisado, sem saber quem era o outro corretor.

## Critérios de aceite
- [ ] Corretor entra na fila de uma data ocupada
- [ ] É avisado quando a data libera, sem revelar a identidade de ninguém
