## Contexto
Depois da estadia, o proprietário registra como foi o hóspede, para decidir sobre reservas futuras.

## Critérios de aceite
- [ ] Após o check-out, o proprietário avalia (nota e observações, com campos estruturados: danos, barulho, regras, pontualidade)
- [ ] Visível só para o proprietário que avaliou e para a administração; nunca para corretores nem para o hóspede
- [ ] O hóspede é identificado só pelo nome informado na proposta; sem dados pessoais além do necessário
- [ ] Ao receber nova proposta com o mesmo hóspede, o proprietário vê o histórico dele nas casas dele
- [ ] Edição com histórico, exclusão a pedido e retenção definida (LGPD)
- [ ] Testes de privacidade (corretor não acessa) e de permissão
